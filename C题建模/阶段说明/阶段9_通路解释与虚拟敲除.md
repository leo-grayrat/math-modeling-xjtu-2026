# 阶段 9：通路解释与虚拟敲除

## 先说结论

本阶段不再训练一个新模型，而是把阶段 7 已经确定的模型当作一台固定机器，观察“把某个基因的表达逐步关小”以后，这个细胞的通路、八个功能模块和最终预测会怎样变化。

三个典型案例都出现了同一种稳定现象：敲除强度从 50% 增至 100% 时，相关通路和模块的变化同步增大；最终依赖性预测只发生小幅变化。它说明模型能够沿着基因所属通路把局部扰动传到细胞功能表示中，同时总体预测没有被一次局部改动剧烈推翻。这里展示的是模型敏感性，不能写成真实生物实验或因果证明。

## 实际操作方法

### 1. 怎样模拟“关闭一个基因”

题目中的表达量原本是 `log(TPM+1)`。真正关闭表达时，先把原始表达设为 0，再用该基因在全部细胞中的均值和标准差换成 z-score。不能直接把 z-score 设为 0，因为 z-score 的 0 只表示“处在平均水平”，并不表示没有表达。

对每个案例分别模拟 50%、75% 和 100% 三档扰动。其余基因表达保持不变，避免把一次局部实验变成整张细胞表达表的重造。

### 2. 怎样把变化传到通路和模块

先根据基因元数据确定目标基因属于哪些通路，只更新这些通路的平均表达分数；随后沿用阶段 3 已经冻结的 Bartlett 计算方法，重新得到八个模块得分。模块载荷、命名和阶段 7 模型参数均不重新训练。

代码另外检查了两件事：

- 扰动强度为 0 时，核相似度和预测必须还原阶段 7 原值；
- 标签基因和表达矩阵中的基因顺序可能不同，必须先按基因名称重新对齐，不能把同一个行号当作同一个基因。

第二项检查在冒烟测试中实际发现并修正了一次错位。修正后，`HSPE1` 只改变伴侣蛋白及其上层归属通路，不再错误影响铁硫相关通路。

### 3. 怎样选择案例

案例只根据冻结模型的预测值和通路资料选择，不查看这些组合的真实标签。最终选取三个不同细胞、三个不同基因：

- `ACH-000618—HSPE1`：蛋白稳态和伴侣蛋白；
- `ACH-002677—PRELID1`：心磷脂合成和脂质代谢；
- `ACH-002475—ISCU`：铁硫簇合成和金属辅因子代谢。

这样既能覆盖不同机制，也不会只挑一个偶然变化最大的对象反复讲。

## 数学建模方法

设目标基因关闭后的标准化表达为

```text
z_knockout = (0 - 该基因表达均值) / (该基因表达标准差 + 1e-8)
```

扰动强度为 `r` 时，在原表达和完全关闭表达之间线性插值。若某条通路包含该基因，就重新计算通路内基因 z-score 的平均值；再用阶段 3 的固定载荷和 Bartlett 规则更新模块得分。更新后的细胞特征重新计算它与训练细胞的 RBF 核相似度，最后送入阶段 7 的两步核岭模型。整个过程只改变当前细胞的一行特征，不重新拟合模型。

## 三个案例的结果

| 细胞—基因 | 100% 敲除时主要通路变化 | 最大模块变化 | 最终预测变化 |
|---|---|---:|---:|
| ACH-000618—HSPE1 | Chaperones `-0.8688` | 脂肪酸和支链氨基酸利用 `+0.2378` | `-0.0169` |
| ACH-002677—PRELID1 | Cardiolipin synthesis `-0.6757` | 维生素-血红素与能量缓冲 `+0.4028` | `+0.0180` |
| ACH-002475—ISCU | Fe-S cluster biosynthesis `-0.4455` | 维生素-血红素与能量缓冲 `-0.1571` | `-0.0019` |

三档扰动的通路变化范数和模块变化范数都随强度单调增加。例如 `HSPE1` 的模块变化范数从 `0.2301`、`0.3451` 增至 `0.4602`；`PRELID1` 从 `0.2210`、`0.3315` 增至 `0.4420`。这说明变化链条是连续的，没有出现“轻微扰动突然跳到完全不同状态”的数值异常。

最终预测的变化明显小于中间通路和模块变化。原因是阶段 7 同时综合完整表达、通路、疾病类型、模块和基因资料；单个基因只改动其中一小部分。论文中可把它解释为模型对局部功能变化有反应，但总体判断由多类信息共同约束。

## 输出文件

- `results/stage9_case_pathway_changes.csv`：各档扰动下的通路变化；
- `results/stage9_case_module_changes.csv`：八个模块的同步变化；
- `results/stage9_counterfactual_predictions.csv`：扰动强度、预测变化和变化范数。

```powershell

```

## 使用边界

虚拟敲除回答的是“按照当前模型，如果只改变这一项，预测会怎样移动”。它不能替代真实敲除实验，也不能证明通路变化一定由该基因造成。论文中应使用“模型模拟”“敏感性分析”和“可能影响”，避免使用“证实”“导致”等因果措辞。
