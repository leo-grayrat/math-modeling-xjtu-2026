# 阶段 4：基因普遍重要性

本阶段先回答一个基础问题：训练标签里没有出现过的新基因，能不能只看题目给它的那张“资料卡”，先估计一个大概的基础重要性？这张资料卡就是 `gene_metadata.csv`，包括基因在线粒体中的位置、所属通路、靶向信号、结构域、同源性、共表达和质谱等证据；这里的“重要性”不是泛泛的生物学评价，而是题目中的依赖性分数，分数越大，表示细胞越依赖这个基因，敲除后越容易出现生长劣势。结果是资料卡能提供一些新信息，但不能完全替代真实实验标签。训练集在固定冷启动划分后有 793 个旧基因，外层验证包含 933 个基因、265065 个细胞—基因组合；基因元数据覆盖全部这些基因，但 `pgc_induction_score` 缺失 577 项，`targetp_score` 缺失 305 项，因此统一做中位数填补，并把缺失情况保留为特征。

## 实际操作方法

1. 读取基因元数据，保留三个数值证据分数、证据/通路/别名数量、描述长度，以及线粒体位置、结构域、同源证据和质谱证据等分类字段。
2. 只用外层训练部分的 793 个基因计算“基因平均依赖性”，不偷看外层新基因的标签。
3. 在这 793 个基因内部再留出 20% 做惩罚参数选择，避免用外层验证结果调参。
4. 生成五组预测：基因均值基线、纯元数据岭回归、纯元数据 LASSO、岭回归混合方案、LASSO 混合方案。
5. 混合方案对训练中已经出现过的基因继续使用实测基因均值；只有新基因才使用元数据模型预测。这样比较的就是元数据是否真的解决了冷启动，而不是让元数据去替代已经拥有的实验信息。

## 数学建模方法

把每个基因的元数据整理成特征向量 `x_g`，把训练标签按基因求平均得到目标 `m_g`。岭回归求解

\[
\min_{\beta}\sum_g(m_g-\beta_0-x_g^T\beta)^2+\lambda\|\beta\|_2^2,
\]

LASSO 则把最后一项换成 `\lambda\|\beta\|_1`，用来观察哪些证据字段在收缩后仍然保留。所有数值特征先按外层训练基因标准化，分类字段采用基准类别编码。惩罚参数分别由内层基因验证集选择，最终只在固定的四类冷启动验证上比较。

## 结果

| 方案 | 官方验证总分 | 说明 |
|---|---:|---|
| 基因均值 | 53.081 | 已见基因的强基线，新基因退回全局均值 |
| 纯元数据岭回归 | 32.309 | 对所有基因都只看元数据，损失了已见基因的直接信息 |
| 纯元数据 LASSO | 32.027 | 与岭回归接近，不能单独使用 |
| 混合岭回归 | **54.676** | 新基因用元数据，旧基因保留实测均值 |
| 混合 LASSO | 54.584 | 略低于混合岭回归，作为敏感性对照 |

在旧细胞—新基因组中，基因均值基线的 RMSE 为 `0.3718`，混合岭回归降到 `0.3557`；在新细胞—新基因组中，RMSE 从 `0.3747` 降到 `0.3583`。这说明元数据确实提供了新基因的额外信息，但提升幅度有限，仍然不能只靠基因资料完成可靠排序。

## 阶段结论与边界

后续保留“混合岭回归”作为基因基础分的默认方案，理由有两点：第一，旧基因已经有真实标签，继续使用实测基因均值比重新看元数据更可靠；新基因才使用元数据岭回归。第二，在固定验证中混合岭回归总分为 `54.675535`，高于混合 LASSO 的 `54.584252`，而且新基因组的排序表现略好。当前元数据字段之间有明显重叠，岭回归会保留多条相关证据的合并作用，LASSO 则可能只留下其中一条，因此 LASSO 暂作为敏感性对照，不作为默认路线。下一步需要加入细胞个体差异，否则同一个基因会被所有细胞预测成同一个基础分。本阶段没有使用细胞—基因交互，也没有进入虚拟敲除和正式测试预测。
