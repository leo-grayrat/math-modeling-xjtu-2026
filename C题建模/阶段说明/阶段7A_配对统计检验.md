# 阶段 7A：配对统计检验

本步没有重新训练模型，而是把阶段 7 已冻结的 1019 个验证细胞作为配对单位，重复抽取细胞 10000 次并在每个细胞内随机交换底座与两步核岭预测 10000 次。官方总分提升为 `0.638192`，细胞 Bootstrap 的 95% 区间为 `[0.505056, 0.772779]`，单侧配对置换检验 `p=0.0001`；NDCG、Precision 和 RMSE 的改善区间也都高于 0，说明提升并非只由少数细胞偶然造成。Spearman 变化为 `-0.002324`，95% 区间跨过 0，仍应在论文中如实写成“没有证据表明整体排序得到改善”。本步只补充稳定性证据，不把显著性作为采用模型的唯一理由，也没有继续调整模型参数。
