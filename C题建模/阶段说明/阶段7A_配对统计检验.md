# 阶段 7A：配对统计检验

本步没有重新训练模型，而是把修正后的阶段 7 预测按 1019 个验证细胞配对，重复抽取细胞 10000 次，并在每个细胞内随机交换底座与两步核岭预测 10000 次。官方总分提升为 `0.614426`，细胞 Bootstrap 的 95% 区间为 `[0.483544, 0.746307]`，单侧配对置换检验 `p=0.0001`；NDCG、Precision 和 RMSE 的改善区间也都高于 0，说明综合提升并非只由少数细胞偶然造成。Spearman 变化为 `-0.002612`，95% 区间为 `[-0.005223, -0.000097]`，表明长名单整体排序存在稳定但很小的下降。论文可以用总分、前列命中和误差结果支持采用模型，但不能声称所有指标都改善；若篇幅有限，可不展开逐项假设检验。本步只补充稳定性证据，没有继续调整模型参数。
