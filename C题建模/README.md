# C 题建模工作区

整体进度见 `论文工作总清单.md`；每一步的一段话说明单独放在 `阶段说明/` 中。

## 这一阶段先做什么

C 题后面要预测“某个细胞敲掉某个基因以后，会受到多大影响”。在开始做模型以前，第一件事是把训练数据和待预测数据分清楚，并确认测试中哪些细胞、哪些基因是训练时没有见过的。

这一阶段不训练高阶模型，只完成三件基础工作：

1. 用 MATLAB 读入标签、细胞特征、基因资料和提交模板；
2. 检查这些表能不能按细胞和基因正确接上；
3. 建立能模拟正式测试的四类验证划分。

这样做的原因很直接：如果先随机抽取一些数据行作为验证集，同一个细胞和同一个基因往往还会出现在训练集中。模型只要记住它们的平均表现，就可能得到虚高分数，却不能证明它会预测新细胞和新基因。

## 实际操作方法

### 1. 数据从哪里读

正式代码只读取题目原始数据：

```text
2026年校赛题目/C/数据文件/
```

其中：

- `labels/gene_dependency.csv` 是已知实验结果；
- `submission/sample_submission_gene.csv` 是需要预测的细胞—基因组合；
- `features/` 描述每个细胞的表达状态和通路状态；
- `metadata/` 描述细胞、基因和通路的基本资料。

原始文件保持只读。程序产生的小型分组表放到 `data_processed/`，统计结果放到 `results/`。

### 2. 怎样判断新旧对象

先列出训练标签中出现过的全部细胞和基因，再逐行检查提交模板：

| 组别 | 实际含义 |
|---|---|
| 旧细胞、旧基因 | 两边都在训练中见过 |
| 旧细胞、新基因 | 细胞见过，基因没见过 |
| 新细胞、旧基因 | 细胞没见过，基因见过 |
| 新细胞、新基因 | 两边都没见过 |

正式测试中最难的是后三组，尤其是“新细胞、新基因”。

### 3. 怎样制作内部验证集

内部验证不按行随便抽样，而是先固定一批不参加训练的细胞和基因：

- 留出约 11% 的训练细胞，模拟正式测试中的新细胞；
- 留出约 15% 的训练基因，模拟正式测试中的新基因；
- 所有涉及这些对象的标签都进入验证集；
- 在剩余的旧细胞—旧基因组合中，再留出约 8% 的行作为普通插值验证。

随机种子固定为 42。留出的细胞和基因名单会单独保存，后续所有基线和主模型使用同一份划分。

## 数学建模方法

这一阶段的数学工作只是集合划分，还没有进入回归或因子模型。

把训练中出现过的细胞集合记为 `C_train`，出现过的基因集合记为 `G_train`。对任意待预测组合 `(c, g)`：

- `c` 属于 `C_train` 且 `g` 属于 `G_train`，记为旧—旧；
- 只有 `g` 不属于 `G_train`，记为旧—新；
- 只有 `c` 不属于 `C_train`，记为新—旧；
- 两者都不属于训练集合，记为新—新。

内部验证集用同样的规则，只是把训练数据中的一部分细胞和基因人为当成“没见过”。这样得到的分数，才更接近模型在正式测试中的真实表现。

## 本地讲义怎样用到 C 题

后续方法优先从本地资料中取，不凭空堆算法。

| 本地资料 | 原讲义解决的问题 | 准备怎样改成 C 题 |
|---|---|---|
| `更新2 因子分析模型/因子分析.pdf` | 配套例题用 1984 年洛杉矶奥运会 55 个国家和地区的男子径赛成绩寻找少量共同能力，并用旋转后的载荷解释因子 | 用于把 140 条通路和表达特征整理成少量线粒体功能模块；模块必须能按高载荷基因和通路命名 |
| `第14讲. 主成分分析/代码和例题数据/PCA.m` | 配套代码用相关矩阵、特征值和贡献率压缩 1999 年全国 31 个省份的居民消费指标 | 作为问题一的对照方法，检查细胞表达的主要变化方向；不直接把“主成分 1”当作生物学模块 |
| `更新4 岭回归和lasso回归/岭回归和lasso回归.pdf` | 讲义处理多个自变量彼此相关时的回归不稳定问题，配套资料包含棉花产量数据，并强调标准化、惩罚项和交叉验证 | 用于问题二的基因普遍重要性和细胞修正基线；验证必须按细胞和基因分组，不能照搬随机行划分 |
| `4.清风数学建模公开课的课件/公开课：MATLAB机器学习算法` | 配套材料通过房价、鸢尾花、众筹和泰坦尼克号等例子展示数据整理、训练与评价 | 后续用于整理统一训练流程和指标输出，不直接照抄示例模型 |

当前 MATLAB 只有基础环境、Optimization Toolbox 和 Symbolic Math Toolbox，尚无 Statistics and Machine Learning Toolbox。因此 `pca`、`factoran` 和 `lasso` 暂时不能直接调用。`v1.0` 只使用基础 MATLAB；按照后续安排，先安装统计与机器学习工具箱，再进入简单基线和模块建模。

## 运行方法

从仓库根目录运行：

```powershell
matlab -batch "addpath('C题建模/matlab'); run_stage1_data_inventory(42)"
```

程序会重新生成本阶段的全部 CSV 结果。下一阶段以这些分组为固定验证口径，不重新随机划分。
