# 阶段 7 预处理边界与两条处理路线

## 先说结论

阶段 7 没有把验证集的依赖性标签放进训练，基础分和残差模型都只读取相应训练折的标签。这条最重要的隔离线仍然成立。

问题出在另一层：程序在划分三组内层验证以前，已经把所有对象的公开特征整理好，并建立了完整核矩阵。换句话说，它没有看验证对象的“考试分数”，但提前看到了这些对象的表达、通路、类别等“个人资料”，其中一部分还参与了标尺和相似度范围的确定。因此，当前结果属于**标签隔离、允许使用待预测对象公开特征的半传导验证**，不能继续写成“每个内层折的全部预处理只由本折训练对象估计”。

## 一、程序实际做了什么

| 环节 | 当前做法 | 是否读取验证标签 | 是否使用留出对象公开特征 |
|---|---|---:|---:|
| 基因基础分 | 每折只用训练标签重算已见基因均值和岭回归 | 否 | 内层标准化沿用固定外层训练基因范围 |
| 细胞特征标准化 | 用固定外层训练细胞计算填补值、均值和标准差 | 否 | 内层留出细胞属于这个范围，因此参与内层标尺 |
| 基因特征标准化 | 用固定外层训练基因计算填补值、均值和标准差 | 否 | 内层留出基因属于这个范围，因此参与内层标尺 |
| 类别和证据词表 | 在全部待处理细胞或基因上建立类别列和词条列 | 否 | 是，外层留出对象也可能影响有哪些列 |
| 基因表达轮廓 | 使用 1019 个有标签细胞的完整表达，形成每个基因的表达轮廓 | 否 | 是，内层和外层留出细胞都进入轮廓 |
| RBF 核带宽 | 先对全部细胞、全部基因计算距离，再取整体距离中位数 | 否 | 是，留出对象参与核的尺度确定 |
| 内层核回归 | 从已经建好的完整核矩阵中抽取训练部分并预测验证部分 | 否 | 是，核矩阵在内层划分以前已经建立 |

代码中的关键顺序是：

1. `prepareFullInformation` 先整理全部对象特征；
2. `buildRbfKernel` 随后建立完整细胞核和基因核；
3. `makeInnerSplit` 之后才产生每个内层折的训练和验证标签；
4. `stage7_fit_fold_gene_base` 与两步核岭只使用训练标签拟合。

因此，当前问题不属于直接的标签泄漏。更准确的比喻是：考试答案被锁住了，但出题前已经看过所有考生的体检资料，并用这些资料确定了分组标尺。

## 二、这会怎样影响现有结果

当前 `55.289961` 的外层成绩和三组内层选模结果，可以支持以下说法：

> 在所有待预测对象的公开侧信息都可以预先使用、验证标签完全隔离的条件下，两步核岭回归优于阶段 4 基础分。

它暂时不能支持更强的说法：

> 每次遇到一个此前完全不参与任何预处理的新对象，只用旧对象建立全部标尺，两步核岭仍得到相同提升。

现有证据无法判断严格重建后成绩一定上升或一定下降。核带宽、表达轮廓和类别列都会变化，选中的 `lambda=0.1` 也可能改变。继续沿用原数字可以，但论文必须把验证口径写准确；若要保留“严格归纳冷启动”的表述，就必须重新计算。

## 三、路线 A：每折严格重建全部预处理

### 大白话说明

每次模拟“新细胞或新基因第一次出现”时，只让旧对象决定标尺。新对象可以带着自己的资料来接受预测，但不能参与均值、标准差、词表、表达轮廓长度和核带宽的制定。

### 实际操作

1. 每个内层折单独确定训练细胞和训练基因；
2. 只用这些训练对象计算缺失填补值、均值和标准差；
3. 类别和证据词表只由训练对象建立，验证中没见过的类别归入统一的未知项；
4. 基因表达轮廓只保留训练细胞维度；
5. 核带宽只由训练对象之间的距离确定，再计算训练—验证的交叉相似度；
6. 三组内层重新比较路线和参数，选定后再按固定外层训练对象重建一次全部预处理；
7. 外层仍只运行一次，不能用新结果反复修改方案。

### 优点与代价

- 优点：冷启动口径最干净，论文可以直接写“每折预处理只由训练对象估计”。
- 代价：需要修改特征准备和核计算接口，并重跑阶段 7、配对检验以及受影响的阶段 8、9、10。现有结果可能变化，工作量和返工范围较大。

## 四、路线 B：保留半传导处理并改准论文口径

### 大白话说明

正式测试已经给出了新细胞和新基因的公开资料。模型可以先浏览这些资料的整体分布，但任何隐藏依赖性分数都不能看。这种做法更像“答案保密，考生资料公开”。

### 实际操作

1. 保留现有模型、参数和结果；
2. 删除正文中“每个内层折全部预处理只由本折训练对象估计”的表述；
3. 明确写出标准化使用固定外层训练范围，而类别词表、基因表达轮廓和核带宽允许使用待预测对象的公开无标签特征；
4. 把验证方式称为“标签隔离的半传导冷启动”，并在局限中说明它不等同于完全归纳的新对象预测；
5. 正式测试预测继续沿用同一原则，保证验证与提交阶段口径一致。

### 优点与代价

- 优点：不改动已经冻结的结果，且与题目提供完整测试特征的实际使用场景相符。
- 代价：论文的冷启动主张需要收窄。评审若要求“任何预处理都不能接触验证对象”，这套结果不能回答该更严格问题。

## 五、需要用户决定的地方

两条路线都会保持验证标签隔离，区别在于是否允许公开无标签特征参与预处理。

- 若优先追求最严格、最容易解释的验证口径，选择路线 A；
- 若优先保持现有结果，并把场景限定为题目实际提供全部侧信息的预测任务，选择路线 B。

在用户明确选择以前，不修改论文中的最终口径，不重跑阶段 7，也不让后续 Issue 假定其中一条已经获批。
