## 1. 统一图表契约

每张正式图在写代码前先填写五项：

1. **核心结论：** 这张图要让读者记住什么；
2. **证据链：** 每个面板提供哪一块独立证据；
3. **图型：** 根据变量含义选择，不为追求新颖强行使用复杂图型；
4. **数据来源：** 精确到结果 CSV、字段和筛选规则；
5. **输出要求：** Python 绘图，统一配色，导出可编辑 SVG/PDF 和高分辨率 TIFF/PNG，图例、样本量、误差定义和题注同步记录。

统一视觉规则如下：

- **后端：** 只使用 Python 完成绘图、预览、导出和视觉检查；
- **基础色板：** `#6AD1A3`、`#7FBDDA`、`#BBC7BE`、`#FFD47D`、`#FFA288`、`#C49892`、`#929EAB`、`#84ADDC`。这些颜色用于建立统一语汇，不是只能机械排列的八个色块；连续变量应由相应端点生成有意义的明暗或方向色阶；
- **方向语义：** 绿色优先表示改善，珊瑚色优先表示下降或风险，灰蓝用于基础模型和中性参照；同一模型、对象状态和变化方向在全文保持一致；
- **字体：** 中文使用 FandolSong，必要的中文辅助字形使用 FandolKai/FandolFang；英文使用 TeX Gyre Termes Regular/Bold；数学符号使用 Computer Modern/AMS；
- **线条与边框：** 不给柱体和色块机械添加黑边，不把“一条线加一个圆”当成默认图型；线和点只有在分别表示区间、估计或趋势时才同时使用；
- **文字位置：** 画布内只保留轴、刻度、短标签、必要图例和面板编号。方法说明、筛选原因、颜色解释和结论句进入图题或图注，不在图中用自由文本找补；
- **预览门禁：** 一次只生成一张 PNG 预览，审阅通过后才导出 SVG、PDF、TIFF 和最终 PNG；未通过的预览留在独立绘图分支，不直接合入论文主线。

## 3. 逐图契约

### 图 1：`Our Work` 总体路线图

- **核心结论：** 本文不是把两个问题分开做，而是把细胞功能表示、基因基础分、双侧修正和输入敏感性检查串成一条路线。
- **信息层级：** 左侧为题目输入；中间上方为问题一的 113 条通路→8 模块；中间下方为问题二的基因基础分→两步核岭；右侧为四类冷启动预测和虚拟敲除输入敏感性检查。
- **图型：** `schematic-led composite`，使用四个大模块和单向箭头，避免塞入模型公式和具体得分。
- **外部生图：** 详细提示词见 `C题建模/figures/prompts/图1_Our_Work_外部Imagen提示词.md`；图片返回后检查文字、箭头关系和敏感性解释边界。Python 不伪造概念图中的数据。
- **正文落点：** 第二节问题分析、第五/六节开头。

### 图 2：数据结构与四类冷启动

- **核心结论：** 新细胞、新基因和双冷启动是本题的核心难点，不能被普通随机行拆分掩盖。
- **面板 A：** 训练标签、正式模板和特征表的连接关系；
- **面板 B：** 四类测试组合数量；
- **面板 C：** 训练中见过/未见过的对象集合示意。
- **推荐图型：** 组合条形图 + 简洁集合示意；不要使用 3D 图。
- **正文落点：** 第一节问题重述、第二节数据分析、第四节验证设计。

### 图 3：通路载荷热图

- **核心结论：** 8 个模块可以由成组的末级通路解释，而非只有“因子 1、因子 2”。
- **面板：** 行为模块，列为各模块前若干高载荷通路；颜色表示载荷大小和方向；模块 8 以探索性标记。
- **数据规则：** 只显示排名靠前的载荷以保证可读性，完整载荷表放附录或支撑材料；不能静默删除通路，须记录筛选规则。
- **推荐图型：** 分块热图，模块分隔线和直接标签优先于大图例。
- **正文落点：** 第五节模块命名和选择结果。

### 图 4：不同谱系的八维模块状态

- **核心结论：** 不同肿瘤组织谱系呈现不同的八维功能模块组合，聚合后比八组标准化分布更有信息。
- **图型：** 单面板热图；行为样本量不少于 10 的 24 个谱系，列固定为 M1—M8。
- **数据规则：** 按谱系计算模块平均得分，覆盖 1127 个细胞；谱系按八维平均状态进行 Ward 排序，不画聚类树。
- **视觉规则：** 色阶固定为 `[-2,2]`，仅在 `|平均得分|≥1.0` 时标数；不再绘制没有信息增量的八组分布和近零相关矩阵。
- **正文落点：** 第五节问题一结果。

### 图 5：基因基础分模型比较

- **核心结论：** 已见基因保留实验均值、新基因使用元数据回归的混合策略明显优于所有基因只看元数据；混合岭只比混合 LASSO 小幅占优。
- **面板 A：** 五种基础分方案的官方总分横向条形图；
- **面板 B：** 混合岭与混合 LASSO在两个新基因组相对基线的 RMSE 降低量；
- **数据准备：** 由已有逐行预测和正式评分函数整理可追溯派生表，不重新拟合，也不从 Markdown 手抄数值；
- **视觉边界：** 不使用黑边、棒棒糖或五种高饱和颜色，不把岭与 LASSO 画成压倒性差距。
- **正文落点：** 第六节基础分模型。

### 图 6：两步核岭主模型

- **核心结论：** 模型先估计基因通常有多重要，再利用细胞和基因两侧的相似对象修正当前组合。
- **图型：** `schematic-led composite`；左侧形成基础分，中部形成残差，上下两路分别构造细胞和基因相似度，右侧汇合为最终预测。
- **视觉边界：** 图中只保留四个主要区块、单向箭头、短中文词组和两个核心符号；不放特征维数、成绩、参数搜索和完整公式。
- **制作方式：** 使用 Python 矢量形状精确排版，不调用图片生成模型。
- **正文落点：** 第六节主模型建立。

### 图 7：四类冷启动总分

- **核心结论：** 两步核岭在四类组合中均提高综合评分，新基因相关组改善更明显，但其绝对得分仍明显偏低。
- **上层 A/B：** 旧基因和新基因各一个分面；横轴均为旧细胞、新细胞，每组比较基础分与两步核岭。
- **下层：** 与四组位置对齐，单独展示两步核岭相对基础分的综合评分提升量。
- **尺度规则：** 上层两个分面共享 `0—85`，下层两个分面共享 `0—1.7`；既不通过截断坐标夸大改善，也不让大尺度淹没小幅提升。
- **删减规则：** 本图只展示综合评分；各单项指标的稳定性统一交给图 9。
