# 图 5 基因基础分模型比较

## 核心结论

已见基因保留实验均值、新基因使用元数据回归的混合方案明显优于“所有基因只看元数据”；混合岭与混合 LASSO 很接近，岭回归只是在综合评分和新基因排序上小幅占优，不能画成压倒性胜出。

## 图表契约

- **类别：** 问题二基础分结果图，采用两个并列定量面板。
- **面板 A：** 五种基础分方案的官方总分横向条形图，包括基因均值、纯元数据岭、纯元数据 LASSO、混合岭和混合 LASSO；条形从零开始，并按结果层级而非算法名称着色：混合岭、混合 LASSO 为绿色，基因均值为黄色，纯元数据岭、纯元数据 LASSO 为珊瑚色。
- **面板 B：** 两个新基因组相对基因均值基线的 RMSE 降低量。只比较混合岭和混合 LASSO，横轴分为旧细胞与新细胞，纵轴统一表示“RMSE 降低，越高越好”。四根柱均表示正向改善，因此统一使用绿色系；岭使用深绿 `#3FAE7C`，LASSO 使用浅绿 `#A8E5CA`，通过足够明显的明度差和图例区分。
- **数据准备：** 使用已有五份阶段 4 逐行预测和官方评分函数生成 `results/figure5_gene_base_model_comparison.csv`，不重新拟合模型，也不从 Markdown 手抄总分。
- **颜色规则：** 遵守全文固定的“好—中—差”语义：好或正向使用绿色 `#6AD1A3`，中等使用黄色 `#FFD47D`，差或探索性使用珊瑚色 `#FFA288`。不得为了区分岭与 LASSO 临时增加灰蓝、蓝色等新方法色；同一结果层级中的模型由纵轴标签区分。
- **视觉规则：** 不使用黑边、棒棒糖或五种高饱和颜色；数值只标关键总分和 RMSE 降低量，完整指标保留在结果表。
- **解释边界：** 面板 A 说明混合策略的价值，面板 B 说明岭与 LASSO 的差距很小；不能仅凭 RMSE 把 LASSO 写成失败路线。
- **输出边界：** 第一轮只生成 PNG 预览，确认后再导出完整格式。
