# 图 6 两步核岭主模型结构

## 核心结论

模型先估计基因通常有多重要，再利用细胞和基因两侧的相似对象修正当前组合；基础分与特异修正承担不同任务。

## 图表契约

- **类别：** 方法示意图，采用 `schematic-led composite`，不承载模型成绩。
- **左侧基础分：** 已见基因由训练标签均值得到基础分；新基因由元数据岭回归得到基础分，两条路线汇合为 `b_g`。
- **中部残差：** 训练标签减去基础分形成残差矩阵；未观测组合使用“细胞平均残差 + 基因平均残差 - 总体平均残差”近似填补，并明确标成模型近似。
- **上下双路：** 上路把细胞表达、通路、疾病类型和八模块整理成细胞相似度；下路把基因数值资料、类别、通路、证据和表达轮廓整理成基因相似度。
- **右侧输出：** 两侧相似度共同传递残差修正 `r_cg`，最后用 `预测 = b_g + r_cg` 汇合。
- **视觉规则：** 使用四个主要区块和单向箭头；不列 1123、140、263 等特征维数，不放总分、参数搜索和完整公式推导。
- **文字规则：** 图中只用短中文词组和两个核心符号；较长的填补说明与核岭公式放图注或正文。
- **制作方式：** 使用 Python 矢量形状精确排版，不调用图片生成模型，避免公式和中文文字出错。
- **输出边界：** 第一轮只生成 PNG 预览，确认结构、箭头和文字密度后再导出完整格式。
